# Proyecto-de-programaci-n
## Avance de proyecto de programación
**Contexto**
Nosotros como alumnos llevamos diferentes materias y no todas necesitan el mismo tiempo de estudio que otras, asi mismo muchas veces no nos damos el tiempo de organizar nuestras materias y su respectivo tiempo de estudio. 

Este proyecto propone desarrollar un programa que ayude a los estudiantes a poder organizar sus materias de manera rápida y eficiente, dedicandole más tiempo a las materias díficiles. 
 
 El programa recibirá el número de materias del alumno, sus nombres, su dificultad y cuantás horas y días desea estudiar por semana. Con esos datos este proyecto desplegará que días y que horas se tiene que estudiar cada materia.
